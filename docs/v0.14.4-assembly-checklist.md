# V0.14.4 焊接注意与首板上电检查

整理日期：2026-10-20。适用60×75mm、4层、正面贴装的V0.14.4 Threefix PCB。PCB已到货，本文为装配与验证建议，尚不代表来料、焊点或电源实测合格。软件暂留0.7.0-dev，本轮不修改固件。

## 1. 焊之前先核对

**先完整验证1块，再复制其余板。不要拿旧版BOM、旧钢网或“长得一样”的器件直接装。**

| 位号 | 这次实际装配 | 注意 |
|---|---|---|
| U1 | ESP32-C5-WROOM-1U-N8R8 | 原工程标注N8R4；实际为8MB Flash/8MB PSRAM、外接天线款 |
| U2 | ML307R-DL | 需要实装；此前DFM临时排除不等于不焊，也不能用ML307C固件/型号代替 |
| U4 | SCT2330TVBR | 原BOM为AP63300WU-7；保留现有反馈阻值与6.8uH电感，替料须首板验证；不要混成SCT2330C等其他后缀 |
| U6 | SP3485EN-L/TR | 原BOM为MAX3485ESA+；实际3.3V器件，不能按5V RS485芯片处理 |
| D30 / D33 | 橙色19-217/S2C-AL1M2VY/3T | 本批已接受橙色，不能按旧红灯袋装错；绿灯D31/D34/D36，蓝灯D32/D35/D37 |
| J1 / J2 / J3 | 通用PH2.0立贴4P | 先不加锡干摆：信号脚、固定脚、出线方向与外壳都要吻合；“2mm、4P”不足以证明兼容 |
| J5 | 国产20279-001E-01兼容射频座 | 先核对三焊脚和天线插头；订单不是原装I-PEX或Hirose的证明 |
| RN1～RN5 | 8脚、4个独立电阻的阵列 | 共端排阻不能代；外形约3.2×1.6mm、脚距0.8mm，还需核对端子形状 |

默认不贴：**C50、C51（LTE天线π匹配预留），R32（RS485可选终端）**。不要把预留焊盘随手短接或补0Ω。R50是已装配的射频串联0Ω，R60/R61是LTE USB串联0Ω；不要混淆。

板上104个实例中，99件为默认实装；另有C50/C51/R32三个预留件，J6/J7两组治具焊孔不采购连接器。此前订购的U1、U2、U6、J4、C80/C85等部分器件正好够5板，操作前先清点实物，尽量避免返修损耗。

## 2. 焊接方式、顺序与受热

1. 先检查板号、铜皮/阻焊、刮伤和毛刺；按采购袋逐项分料。用放大镜、万用表和防静电措施，不凭0603电阻外观认阻值。陶瓷电容通常没有容量字样。
2. 先干摆U1/U2、U5、J4、PH插座和J5，核对封装、1脚与接触位置。原板不少位号被隐藏，找不到位号时看PDF定位图和EDA焊盘号，不猜位置。
3. 首板建议先局部焊完整电源链及其反馈/去耦，再限流测出3.8V和3.3V；电源通过后再装昂贵模组。每个电源阶段都须保持输入/输出电容和反馈回路完整，不能只焊U4/U5就通电。
4. 小而低的器件和细脚IC先就位；模组与带底部焊盘器件安排可控回流，最后处理易遮挡、耐热受限的高大连接器和局部补焊。两模组尽量一次完成各自回流，后续避免整板反复过炉。
5. 自然冷却、清洁并彻底干燥后，放大检查、测阻，再上电；天线、SIM和线束在冷却后连接。

**加热台不能只焊外圈。** U1/U2的底部地焊盘、U5的WSON中心散热焊盘需要真正润湿；用薄而均匀、与当前钢网相符的锡膏，不能在模组下面堆锡把器件顶浮。若底部焊点不能可靠完成，优先改善可控回流/请有条件的装配方处理，不要只焊四角就认为焊完。

**温度按锡膏与整板最敏感器件共同决定。** 先确认是SAC305、Sn63还是SnBi低温锡膏；加热台/热风机设定值不是焊点实温。乐鑫针对SAC305给出的模组峰值参考为235～250°C，并要求单次回流；这不是“全板直接设250°C”的指令。ML307硬件手册亦要求避免反复受热；热风不能长时间直吹塑料插座、SIM座和射频座。[S1][S2]

U1按原厂MSL3管理：标注条件下开袋168小时内焊接，超期或湿敏卡异常按实际包装/厂家要求烘烤。不要把已装塑料插座的整板直接套用模组烘烤温度，也不要用家用食物烤箱。清洁剂需与助焊剂、塑料和模组兼容；乐鑫不建议超声清洗模组。[S1]

## 3. 极性、方向与易桥连位置

下文“上/下/左/右”仅指**从元件面看：J1/J2/J3在下方，J6/J7治具孔在上方**。翻到背面、转板或看线束插头时不能直接沿用左右。PDF定位图标出的1脚点来自定版焊盘，字体朝向不能代替1脚标记。

| 位号 | 必查点 |
|---|---|
| D1 SS34 | 带线端/阴极K接1脚VIN_DIODE；阳极A接2脚VIN_IN。按上述视角，K朝下，向现场接口一侧 |
| D4 SMBJ12A | **单向A型号**，K接1脚VIN_PROT、A接2脚GND；上述视角K朝左。不是SMBJ12CA |
| C80 / C85 | 220uF/6.3V有极性电容：1脚正极VDD_4G在左，2脚负极GND在右。Panasonic SVPC顶面标记指负极，不能套用钽电容色条习惯 [S3] |
| U4 | 1脚FB、2脚EN、3脚VIN、4脚GND、5脚SW、6脚BST；本板1脚在器件右下。重点防VIN/SW/FB桥连 |
| U5 | 1脚OUT、2脚FB、3脚GND、4脚EN、5脚DNC不接、6脚IN；中心7焊盘接GND。本板1脚在左上，中心不能虚焊，也不能堆锡顶起 [S4] |
| U10 / U12 / Q1 | 都是易装反的小封装，按各自1脚/型号核对；不能把SC70、SOT363、VSSOP当成同一种六/八脚件。U10用于LTE低压侧与3.3V侧转换 |
| D18 / D20 | TPD2EUSB30DRTR为约1.0×0.8mm的DRT三脚封装，**不是普通SOT23**。3脚接GND，两个信号脚不能桥地 |
| D5～D13 | D5为三脚SM712保护阵列；D6/D7等双向TVS与D11～D13等单向器件不能凭“D”位号认方向。按实际厂商、精确后缀、封装和脚图核对；CJ SMF12CA来料资料仍需核实 |
| D30～D37 | 1脚K接GPIO低有效端，2脚A经限流电阻接3.3V。边缘六灯K朝下；D36/D37的K朝左。微型灯底面符号各厂家不同，先测一颗确认 |
| J4 / J5 | SIM卡座的信号弹片与壳体地要分清；J5仅2脚是LTE射频，1/3为地。中心不能连地、不能塞满焊锡，冷却后垂直扣接天线 |

U1是1U外接天线款，自带天线座接2.4/5GHz双频天线；板上J5用于LTE，二者不是同一个馈电点。射频座焊牢后再扣线，避免横向撬起；通电做联网前分别接好匹配天线。

## 4. 排阻和反馈阻值：上电前用表确认

| 位号 | 每路阻值 | 常见标法 | 检查 |
|---|---:|---|---|
| RN1 / RN2 | 1kΩ | 102 | LED限流，不是100Ω |
| RN3 | 10kΩ | 103 | 含EN/BOOT/启动相关上拉，桥连可能导致无法启动/下载 |
| RN4 | 100kΩ | 104 | LTE相关上拉；部分独立路未用，空焊盘不是让你短接 |
| RN5 | **22Ω** | 220或22R0 | SIM串联电阻，不是220Ω |

结构应为1-8、2-7、3-6、4-5四对独立电阻。装板前测四对阻值、跨对不共端；采购替料未证明符合该拓扑时不要先焊。阵列没有二极管式极性，但不能旋转90°或把共端件代入。[S5]

- R90=75kΩ、R91=20kΩ：VDD_4G理论为0.8×(1+75/20)=**3.80V**。焊错成7.5k/200k等会改变电压；U4替料的0.8V反馈参考已核对，动态性能未验收。[S6]
- R94=100kΩ、R95=20kΩ：VDD_3V3理论为0.55×(1+100/20)=**3.30V**。U5输入是VDD_4G，不是VIN_IN。[S4]
- R35=100Ω、R36=330Ω、R30/R31=10Ω、R15/R16=22Ω，别与22Ω排阻/100k上拉混料。电阻档在板测量会受并联支路影响，疑点应断电并按电路分开确认。

## 5. 分阶段上电：不跳过电源检查

**这版不按24V板使用。** 虽然U4芯片标称能承受更高输入，整板还有12V TVS和F1=1812L200/16DR（16V额定上限），单芯片耐压不能替代整板输入规格。首板仅电源区域验证建议用可调电源**9V、50～100mA限流起步**，这是调试建议，不是已验收的整板工作范围或满载限流值。[S7]

上电前：取下SIM、不接业务线、不插USB；先测VIN_IN/VDD_4G/VDD_3V3对GND有无明显低阻短路。电容会充电、蜂鸣阈值各表不同，不能只凭一声蜂鸣判短；记录读数和变化，异常先排查。用细表笔、防相邻脚打滑。

| 检查阶段 | 测量与通过条件 |
|---|---|
| A. 仅完整电源区域、暂不装U1/U2 | VIN_IN → D1 → F1 → VIN_PROT链路正确；确认D1/D4方向、反馈与所有必要电容。短时限流上电，3.8V与3.3V接近计算值、无持续限流或异常发热后再继续 |
| B. 加入ESP及其必要外围 | 断电、放电、复查焊点与测阻；再限流启动。按实际启动需要提高限流，不把A阶段50～100mA当整板标准。先确认3.3V稳定，再做USB识别/现有固件下载；GPIO、EN、BOOT不接5V |
| C. 加入ML307及其电源/控制/电平转换 | 断电安装、复查后再上电。先看3.8V稳定、实际VBAT供电和焊点，再做AT；联网前接LTE天线并断电装SIM。LTE突发负载会暴露电源问题，不靠不断提高电压解决重启 |
| D. 完整首板 | 在可控供电下查纹波、启动、LTE发射负载突变和温升；U4替料须在这一阶段验证。未焊前述阶段而已全装完，也要先测阻、限流短时检查电源；不能照A阶段空载电流解释整板 |

| 测点（均相对GND） | 预期与位置 |
|---|---|
| VIN_IN | J1/J2/J3的1脚；三处为同一电源网，不是三个独立输入或5V输出 |
| VIN_PROT | C1/C90的1脚；经过D1/F1，会有器件压降 |
| VDD_4G | C93/C94/C80/C85的1脚，约3.80V；**L1的2脚是输出，1脚是开关节点LTE_SW** |
| VDD_3V3 | C98或C11的1脚，约3.30V；防止误把3.8V送到ESP |
| LTE_VDD_EXT | 模组启动后可测U10的6脚；属于ML307低压逻辑侧，按模组资料核对，未启动没有电压不能先判坏 |

一旦持续限流、输出明显错误、器件快速发热或异味，立即断电并记录；不得带电补焊、跨接反馈电阻或跳过保护件“试试看”。不要在LTE_SW上用长地线当电源纹波测量，正式纹波测试用短地弹簧/合适探头。

## 6. 接口、完工检查与记录

以下按元件面、现场三插座朝下的视角，J1/J2/J3信号脚从左到右1→4；线束插合面可能镜像，须通断确认，不能只看线色。

| 接口 | 1脚 | 2脚 | 3脚 | 4脚 | 5脚 |
|---|---|---|---|---|---|
| J1 RS485 | VIN_IN / P | A | B | GND | - |
| J2 RS232 | VIN_IN / P | TX | RX | GND | - |
| J3 TTL | VIN_IN / P | TX（3.3V） | RX | GND | - |
| J6 ESP治具孔 | GND | USB D+ | USB D- | EN | BOOT |
| J7 LTE治具孔 | GND | USB D+ | USB D- | USB VBUS | LTE启动治具信号 |

**J6的第4脚是EN，绝不是USB 5V！** J6不能靠USB 5V给板供电。J7与J6的第4/5脚定义不同，不能直接互换治具线。ESP首次USB调试只接J6对应D+/D-/GND，并由VIN供板电；J7的VBUS按ML307手册/专用治具处理，不与EN或主VIN混接。

TTL台架只连接适配器TX→J3.3、RX→J3.2、GND→J3.4，不把适配器5V/VCC接到J3.1。三现场接口共用一组UART，首轮TTL只接这一口，不同时接另外两口。

完工逐项勾选：

- [ ] 器件料号/后缀、PCB/钢网版本一致；PH与射频座实物对位完成。
- [ ] U1/U2/U4/U5/U6/U7/U10/U12/Q1方向正确；底部焊点工艺完成，无浮高。
- [ ] D1/D4、C80/C85和八颗LED极性复核；单/双向保护件未混料。
- [ ] RN1～RN5拓扑与阻值正确；反馈电阻、0Ω与默认不贴位复核。
- [ ] 放大检查相邻脚桥连、锡珠、虚焊和SIM弹片；清洁后已干燥。
- [ ] 断电测阻、限流供电、3.8V/3.3V、启动与温升均有记录。
- [ ] 天线对应正确、USB治具针序确认、TTL交叉连接与共地确认。

记录：板号____；操作者____；日期____；锡膏/批次____；焊点实温记录____；输入____V/限流____A；VIN_PROT____V；VDD_4G____V；VDD_3V3____V；异常与返修____；复测人____。

裸ESP未写应用时不亮灯不能直接判焊坏；当前0.7.0-dev支持显式逐灯测试，且未接MQTT，自动模式蓝灯不亮可能完全正常。先完成电源和焊点检查，再按既有首板软件指南测试，不为了亮灯改电路。
