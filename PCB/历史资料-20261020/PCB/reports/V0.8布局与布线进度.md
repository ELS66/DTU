# V0.8 布局与布线进度

2026-10-10。电路沿用 V0.6 精简版，本版调整布局和布线。工程已保存，尚未完成，不可投板。

## 已完成

- 重排 MAX3221 与电荷泵电容 C30～C33，清除局部旧走线。六段电荷泵连线长度约 1.76～3.91mm，补齐移位器件的接地。
- 调整 ESP32 启动配置电阻 R11、R13，打开 GPIO 出线空间。补齐 ESP32 绿、蓝灯网络及部分 TTL、接口控制、检测和启动配置走线。
- 保留 USB 主干原有等长几何；改走局部 3.3V 电源支路，避开 USB 底层主干的地参考投影。
- 按最终过孔重新生成 L2 接地填充，共 275 个图元；增加 L3 的 78 个 USB 局部地参考图元。四段底层耦合主干的铜线投影均被地参考覆盖；焊盘、过孔和扇出区域仍有避让，不代表阻抗或信号完整性验证通过。
- 实际 PCB 焊盘回读通过：173 个器件、587 个实体焊盘、516 个带网络焊盘，与 V0.6 网络清单匹配。器件与电阻数量未改变。原理图的 508 项断言为此前 V0.6 验证，本轮未重跑。
- 工程备份 ZIP 共 13 个条目，完整性检查通过。预览仍有密集丝印和飞线，需继续整理。

## 下一步

1. 优先补齐 U7、C34 和部分检测上拉电阻的 3.3V 供电，重排局部障碍后连接；保留 L2 接地层。
2. 完成 SIM、MCU 与 LTE UART、外部接口和指示灯剩余连接，必要时调整局部器件布局。新增非接地过孔后必须重算地铜避让。
3. 检查 LTE 射频接地、供电线宽和峰值电流、接口保护协调、SIM 检测极性及元器件采购属性。
4. 整理丝印，完成整体电气与物理审查、最终 ERC/DRC 和制造叠层确认后，再输出生产文件。当前不生成生产 Gerber。
