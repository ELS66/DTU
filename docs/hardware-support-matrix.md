# ESP32-S3 硬件验证清单

| 项目 | 当前状态 | 验证方式 |
|---|---|---|
| ESP32-S3 模组与 Flash 容量 | 未选 | 记录型号、Flash/PSRAM，评估 OTA 双分区与缓存预算 |
| WiFi | 待开发板 | 配网、TLS MQTT、断线重连与弱网 |
| TTL 串口 | 待开发板 | 电平、波特率、RTU 测试从站 |
| RS232 | 待收发电路 | 电平转换、线缆与 RTU 测试从站 |
| RS485 | 待收发电路 | 半双工方向、终端与偏置、隔离、RTU 测试从站 |
| 三接口同时运行 | 未确认 | 明确产品要求后检查 UART 与引脚分配 |
| OTA | 待模组 | 分区、签名、自检、掉电回滚 |
| 现场设备 | 未提供 | 获得寄存器表后补真实设备兼容测试 |

首版软件暂按三个接口任选其一作为活动业务通道。实际 PCB、供电和安全保护由硬件设计确认。
