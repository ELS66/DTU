# V0.13 60×70 mm 正面贴片四层板验收包

本包是工程复核版，尚未通过厂家在线 DFM 或首板测试。

1. 用嘉立创EDA打开 `.epro2` 工程。
2. 厂家 DFM 请上传 `DTU-V0.13-60x70-SMT-4L-Gerber-DFM.zip`，不要上传整个资料包。
3. 贴装使用 BOM-99 与 CPL-99-Top，两者均为 99 件、正面装配，已排除 DNP。
4. 阅读《V0.13-整体验收记录.md》。当前 PCB DRC 0 项错误；原理图仍有 18 条绘图/匹配码属性警告，未屏蔽。
5. 接口为 PH2.0 4P 侧插贴片座 C265102，在正面焊四根信号脚和两侧固定片；采购按指定型号。
6. 生产丝印只保留接口名称及针序。以后自行导出时须取消器件丝印/ComponentSilkscreen，避免库外框重新输出。
7. `Gerber-top.png` 是由实际导出层绘制的预览；`placement-1.png` 是封装外形布局示意，图中位号用于对照装配，不代表板上印刷。
