# 自动接口选择校验 V0.3

2026-10-09；工程：DTU-C5-Air780EPT-HW-V0.1-library。

结论：原理图网表与稳态逻辑模型检查通过。取消人工模式拨码，按每组接口 VIN 的供电状态自动选择；优先级 TTL > RS232 > RS485。

检测取自每路保险之后、合路二极管之前。普通 PH2.0 插座没有插入检测开关，只接信号而不给该接口 VIN 供电时不会被识别。沿用断电插拔条件，上电后自动选路；不承诺带电无缝切换。

| TTL 有电 | RS232 有电 | RS485 有电 | 选中的接口 |
|---|---|---|---|
| 0 | 0 | 0 | OFF |
| 0 | 0 | 1 | RS485 |
| 0 | 1 | 0 | RS232 |
| 0 | 1 | 1 | RS232 |
| 1 | 0 | 0 | TTL |
| 1 | 0 | 1 | TTL |
| 1 | 1 | 0 | TTL |
| 1 | 1 | 1 | TTL |

主控未开启总使能或处于复位时，上述 8 种组合均全部关闭。总使能仅用于初始化保护；接口优先级由硬件确定，无需用户选择模式。

检查覆盖：

- 全工程 90 个物理器件唯一标识与位号完整；Air780EPT 三部分合并为 109 引脚，LM339B 四部分合并为 14 引脚。
- 自动选择相关 182 项实际导出引脚网络连接与设计映射一致。
- 三路 VIN 在端子处独立，经过各自保险和阻断二极管后才合路，检测节点未接到公共 VIN_OR。
- 从实际导出的编码器输入分配、译码器使能和输出分配生成稳态模型，验证 16 种组合的选择及复位全关闭。
- 业务 RX 由受控三态接收器共享；74AXP4T245 的未用接收组禁用，TTL RX 经 3.3V 供电的 5V 容忍缓冲器接入。

名义检测计算（VDD_3V3=3.3V、比较器低电平按 0.11V）：进入 4.430V，退出 3.918V；15kΩ/1kΩ 分压节点的 100nF 滤波时间常数约 93.75µs。元件容差、漏电、温度、3.3V 启动波形和接口断电反灌仍须实测，不能把名义值作为保证门限。

验证范围：网表结构和稳态逻辑，未执行全板 ERC、PCB DRC 或实物测试。整板仍有未完成网络，当前不能投板。组合逻辑切换毛刺及保护电路容差需要后续专项检查。
