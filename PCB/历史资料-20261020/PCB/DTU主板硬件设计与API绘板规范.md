# DTU 主板硬件设计与嘉立创EDA API 绘板规范

版本：V0.11；更新：2026-10-12；硬件目录：PCB。

本文件定义当前设计。V0.11 参考 RK_WB4G_V2 实测拓扑简化接口，采用 MAX3485、BL13232E 和三输入与门接收合并。九页原理图与 154 个 PCB 器件已同步；详细检查及剩余事项见 [V0.11 修改与验证记录](reports/V0.11接口修改与验证记录.md)。历史稿中的接口优先级和比较器选路已失效。

## 1. 已确认的需求

| 项目 | 当前规范 |
|---|---|
| 主控 | ESP32-C5-WROOM-1U，当前选用 N8R4；使用模组自带外接天线座 |
| 蜂窝 | Air780EPT，专用 UART 与 ESP32 通信；主板提供独立 LTE 天线座 |
| 接口 | RS485、RS232、固定 5V TTL；各一组 PH2.0 4P |
| 供电 | 从所接接口的 VIN/GND 输入 5～12V，外部电源最大供电能力 2A |
| 使用方式 | **只接一个接口，并由该接口供电；切换前断电。** 不实现多个接口同时接入时的优先级 |
| 指示灯 | ESP 和 LTE 周围各三颗红、绿、蓝独立 LED，从上到下排列；含义由后续程序定义；另设 TX、RX 活动灯 |
| 下载 | 两组 1×5、2.54mm 下载焊孔，默认不焊排针；保留复位/下载按键 |
| 卡座 | Nano-SIM，含电源、信号保护和卡检测 |
| 使用环境 | 室内机柜，无外壳；共地、非隔离；以尺寸和总成本为优化目标 |
| PCB | 当前候选四层、60×70mm；后续完成电源/RF/USB 布线后再评估收缩 |

TTL 的 5V 指 TX/RX 信号。三组端子第 1 脚均为电源输入，不提供外设 5V 供电。只接信号而不接对应 VIN 的方式不支持自动选择。

## 2. 接口与硬件选路

| 端子 | 1 | 2 | 3 | 4 |
|---|---|---|---|---|
| J1 RS485 | VIN_485 | GND | A | B |
| J2 RS232 | VIN_232 | GND | TX（本板输出） | RX（本板输入） |
| J3 TTL | VIN_TTL | GND | TX 5V（本板输出） | RX 5V（本板输入） |

三路 VIN 经各自保险丝、防反接/反灌二极管合路，再进入公共电源保护。无需软件选择接口种类，按一次只连接一个接口设计。

FIELD_TX 共用发送源：连接 U6 的 DI、U7 的 DIN1 和 U8 的 TX 转换输入。RS232 和 TTL 发送输出在供电时跟随该信号；RS485 只在 MCU_485_DE 拉高时驱动总线。程序启动保持 DE=0，发送前拉高，等待 UART 最后停止位完全发出后拉低。此 DE 控制是半双工时序，不是接口配置。

FIELD_RX = 485_RX_RAW AND 232_RX_RAW AND TTL_RX_BUF。三个接收源各接 U12 独立输入，不将推挽输出直接并接。空闲均为高，任一路低使共享接收输出低。未连接接口的空闲状态由接收器和上拉定义。多个接口同时发数据会互相干扰，不属于当前使用方式。

### 2.1 现场接口器件

- U6 MAX3485ESA+（C1545222）：3.3V 半双工 RS485。1脚 RO，2脚 /RE 和 3脚 DE 并接 MCU_485_DE，4脚 DI 接 FIELD_TX；5脚地、6脚 A、7脚 B、8脚 3.3V。保留 SM712、A/B 串联保护。R100/R101 各 270Ω/1% 形成 A 上拉、B 下拉，补足终端负载下的空闲偏置；R32 120Ω 终端默认不装，仅按总线端点需要装配。原 THVD2410 的故障耐压能力不能继承到 MAX3485。[ADI 数据手册](https://www.analog.com/media/en/technical-documentation/data-sheets/MAX3483-MAX3491.pdf)
- U7 BL13232ETS（BL13232E 系列，TSSOP16，C2999161）：3.3V RS232。11脚 DIN1 接 FIELD_TX，12脚 ROUT1 接 232_RX_RAW，13脚 RIN1 和14脚 DOUT1 接现场收发；闲置通道 8脚 RIN2 和10脚 DIN2 接地，7脚 DOUT2 和9脚 ROUT2 不连接。C30/C31 飞跨电容、C32/C33 储能电容各100nF，C34 电源去耦100nF。[贝岭数据手册](https://www.belling.com.cn/media/file_object/bel_product/BL13232E/datasheet/BL13232E_V1.3_en.pdf)
- U8 SN74LVC1T45DCKR（C9382）：保留 TTL TX 的 3.3V→约5.05V 转换，两侧去耦保留。端口不输出5V电源。[TI 数据手册](https://www.ti.com/lit/ds/symlink/sn74lvc1t45.pdf)
- U12 SN74LVC1G11DCKR（C529281）：3.3V 供电的三输入与门，输入允许5.5V，兼做5V TTL 接收转换及三路合并。1脚接485_RX_RAW，3脚接232_RX_RAW，6脚接TTL_RX_BUF，4脚输出FIELD_RX，2脚地、5脚3.3V，C38去耦。R37 100k 定义 TTL 空闲高；R38 10k 上拉 485_RX_RAW，保证 /RE 禁用期间不悬空。[TI 数据手册](https://www.ti.com/lit/ds/symlink/sn74lvc1g11.pdf)

原板二极管合并属于测量支持的候选拓扑，器件型号/极性未完全确认。本版使用与门替代，避免二极管压降叠加收发器最坏 VOL 后对 ESP32-C5 低电平门限余量过小。不照抄原板 DI 接地的逐位发送方案，保留按帧 DE 控制。

## 3. 电源和保护

| 电源域 | 实施 | 限制 |
|---|---|---|
| VIN_OR / VIN_PROT | 三路保险丝、SS34 合路、SMBJ12A、TPS259470 保护 | 入口反接、过流、浪涌、欠压/过压保护；需实测阈值和温升 |
| VDD_4G | AP63200，约 3.8V；6.8µH 电感、220µF 聚合物储能及高频去耦 | Buck 额定 2A，不代表 5V/2A 输入下可以同时满足所有负载峰值 |
| VDD_3V3 | AP63203，3.3V；当前 4.7µH 电感 | ESP32、收发器、LED 和逻辑；电感与稳定性需要按最终 BOM 验证 |
| VDD_5V_IF | TPS61040 从 3.3V 升压，约 5.05V | 仅 TTL 内部电源，当前预算不超过 45mA；不对外供电 |
| SIM_VDD | Air780EPT 提供 | 不连接固定 3.3V 或 5V |

输入最大 2A 是整机边界。最低 5V 时还存在接口、线束和合路二极管压降，必须在 LTE 弱网发射与 Wi-Fi 并发条件下实测 VBAT、3.3V 和输入电流；不能用平均功耗代替瞬态校核。保留反馈、补偿/前馈、启动配置和全部必要去耦。

## 4. 主控、4G 与下载焊孔

专用 UART 保留 TX/RX 和受 LTE_STATUS 控制的断电隔离 U10 SN74LVC2G125。保留 PWRKEY、RESET 驱动；删除无实际用途的 NETSTATUS 辅助反相电路、重复 GPIO 下拉以及 RTS/CTS 通道。当前按无硬件流控通信，固件确认 `AT+IFC=0,0` 和回读结果；Air780EPT 的实际 AT 固件必须验证。[合宙命令文档](https://docs.openluat.com/air780e/at/app/Command_List/Device_control/IFC/)

J6/J7 使用 5 孔封装，默认裸孔；PCB 已安排在模组上方区域。两组脚位不同，不可混用下载夹具。

| 焊孔 | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|
| J6 ESP | GND | USB D+ | USB D− | EN | BOOT |
| J7 LTE | GND | USB D+ | USB D− | USB VBUS 检测 | LTE_BOOT_SOURCE |

整板仍从 PH 接口供电。J6 不引入 USB 电源；J7 USB VBUS 为主机 5V 检测，不给整板或 LTE VBAT 供电。保留 ESP EN/BOOT、LTE BOOT 按键；J7 第 5 脚用于夹具提供下载启动电平，不能直接接主机 5V。USB 差分阻抗、短线夹具和下载流程需要验证。

## 5. 指示灯 GPIO

全部八颗 LED 接 ESP32 GPIO，由程序控制；LTE 周围三灯的颜色不绑定模块供电、运行或联网含义。每灯一颗 1kΩ 限流电阻，连接方式为 3.3V→电阻→LED→GPIO，低电平点亮。GPIO 上电配置输出前先设置高电平。

| 灯 | 颜色 | MCU GPIO | 模组引脚 | 限流电阻 |
|---|---|---:|---:|---|
| D30 ESP 红 | 红 | 2 | 4 | R140 |
| D31 ESP 绿 | 绿 | 4 | 17 | R141 |
| D32 ESP 蓝 | 蓝 | 5 | 16 | R142 |
| D33 LTE 红 | 红 | 7 | 9 | R143 |
| D34 LTE 绿 | 绿 | 9 | 11 | R144 |
| D35 LTE 蓝 | 蓝 | 25 | 26 | R145 |
| D36 TX | 绿 | 11 | 25 | R146 |
| D37 RX | 蓝 | 12 | 24 | R147 |

TX/RX 灯由业务 UART 的收发事件触发，建议亮 50～100ms，持续流量时刷新；不直接挂串口线增加负载。GPIO11/12 是模组 UART0 引脚，本版下载采用 USB，应用将其用作 LED GPIO；启动阶段 TX0 日志可能使 TX 灯短暂闪烁。不得同时在这些脚上启用 UART0 外部收发。N8R4 的内部存储相关引脚不得用于 LED。[乐鑫模组引脚手册](https://documentation.espressif.com/esp32-c5-wroom-1_wroom-1u_datasheet_en.html)

## 6. SIM、射频及默认不装清单

保留 Nano-SIM 卡座、信号串联电阻、低电容 ESD、SIM 电源去耦及卡检测。保留 LTE 50Ω 馈线、U.FL 天线座、串联 0Ω 和匹配位置；ESP 模组使用自己的外接双频天线座，两路天线分开。

| 位号 | 默认装配 | 用途 |
|---|---|---|
| J6/J7 排针实体 | 不装，PCB 裸孔保留 | 下载夹具接触；需时手焊 |
| R32 | 不装 | RS485 120Ω 终端选装 |
| C50/C51 | 不装 | LTE 天线匹配调试后确定 |
| C55 | 不装 | SIM 时钟补偿预留，实测需要时装配 |
| 其余当前 BOM 项 | 默认装配 | 以 BOM-V0.11.csv 为采购/装配清单草稿 |

器件模板料号与实际修改数值尚有匹配警告，采购前必须校准。默认装配 148 件；PCB 上保留 154 个器件位置、56 个电阻位置。

## 7. API 绘制与验证规范

1. 首先核对 Bridge 健康状态和连接窗口，再检查工程 UUID。只操作本次独立工程；工程 UUID 为 1d7fb27b7ad9306bc25c90ee476429c9e681ffecce79136ba05149eca7bba1b0，PCB UUID 为 4211128ecf040c100b33238447713203。
2. 修改前保存并导出 epro2 恢复备份；所有 API Promise 必须 await。每批操作记录成功、失败和保存结果。
3. 原理图使用真实符号/封装，核对数据手册的引脚编号和功能；网络以 revision-v11.json 为预期，导出实际网表逐脚断言，空脚显式不连接。
4. 替换器件时保留 Unique ID；同步 PCB 的 Channel ID、装配标志和所有焊盘网络。删除废弃走线，保留有效既有走线。
5. 库使用原始系统 32 位 UUID 或工程缓存 UUID 配合工程库。缓存短 UUID 不配系统库。下载、LED、电源替换后必须回读实际器件和焊盘。
6. 原理图几何修改在当前客户端存在异常，采用保留 Unique ID 的重建和重连方式；不直接移动该类原理图实例。
7. Bridge 请求超时不等于 EDA 操作停止。长布线任务使用独立状态记录，确认上一个任务已退出再启动下一批，随后回读走线与 DRC。避免再运行大批量 69 网络优化。
8. PCB 采用 L1 信号/器件、L2 连续地、L3 电源/地、L4 辅助信号。关键电源环路优先紧凑布局；LTE 与 USB 按已记录的候选叠层阻抗参数布线，变更工艺后重算。详见四层叠层与阻抗计算记录。
9. 全板连通、间距、装配、丝印、保护协调及实物验证完成后才生成生产输出。Git 提交说明使用中文。
