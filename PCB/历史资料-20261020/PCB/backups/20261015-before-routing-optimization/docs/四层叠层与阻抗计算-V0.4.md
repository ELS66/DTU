# 四层叠层与阻抗计算 V0.4

日期：2026-10-10。工程：DTU-C5-Air780EPT-HW-V0.1-library。

采用 1.6mm 四层候选叠层 **JLC04161H-7628**，外层 1oz、内层 0.5oz。L1 器件与信号；L2 连续 GND；L3 电源/辅助地；L4 辅助信号与地。L1 到 L2 的介质厚度 0.2104mm、介电常数 4.4；量产下单需要选择对应叠层并确认阻抗要求。[板厂叠层](https://jlcpcb.com/impedance)

本记录来自 [JLCPCB 官方阻抗计算器](https://jlcpcb.com/pcb-impedance-calculator) 的计算服务。计算采用其当前外层 1oz / 基铜 0.5oz 配置：铜厚 T1=1.6mil，线顶宽比线底宽小 0.5mil；阻焊 C1/C3=1mil、C2=0.6mil、CEr=3.8。参数与返回结果保存在 [原始计算记录](../reports/impedance-calculation-v04.json)。这些是计算器的工艺模型输入，不能将 T1 直接当作板厂叠层图的名义铜厚值。

| 网络 | 模型与设计尺寸 | 计算结果 | 走线约束 |
|---|---|---|---|
| LTE_ANT / LTE_RF_FEED | 带阻焊共面波导，下方完整地；线底宽 0.32mm；两侧到地铜 0.25mm；两侧地铜各至少 1.016mm | 49.50Ω | L1；L2 不切割；两侧地铜打接地过孔；连接器/串联 0Ω/ESD 的支路尽量短 |
| ESP USB / LTE USB | 带阻焊边耦合微带；单线底宽 0.24mm；两线边缘间距 0.15mm | 90.05Ω 差分 | L1 或对称 L4；连续地参考；相邻地铜/无关线保持足够距离，不能以共面模型混用 |

这两组结果仅适用于上述叠层、工艺模型和几何；更换层叠、铜重、板厂或地铜间距后必须重算。走线完成后检查实际长度差、短分支、焊盘处收窄、转角、过孔和回流路径。
