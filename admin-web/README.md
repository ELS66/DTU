# 管理端开发说明

在此目录运行 `npm ci` 和 `npm run dev`，本地页面默认位于 `http://127.0.0.1:5173`。开发服务器把 `/api` 转发到本机 7926 端口的后端。后端需要设置 `DATABASE_URL`，完成迁移和首个管理员初始化后才能登录。

当前页面支持登录、使用邀请创建账号、切换租户、查看项目、租户管理员创建项目、生成邀请及为已有租户成员设置项目角色。邀请令牌只在创建后显示一次，需由管理员安全交给受邀人；系统不会发送邮件。登录 token 仅保存在当前页面内存，刷新页面后需重新登录。已有账号加入另一租户、现有项目成员查看和其他管理功能尚未实现。
