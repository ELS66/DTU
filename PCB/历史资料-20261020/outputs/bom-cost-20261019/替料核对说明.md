# DTU V0.14.4 免改板降本候选

日期：2026-10-19。适用范围：保留现有功能，五块首板，沿用 V0.14.4 的 PCB 制造文件和贴装位置。

本轮只将 U6 的采购候选改为 **MaxLinear SP3485EN-L/TR（C8963）**。这是参考资料与现有工程的兼容性核对结果，尚无替料实板测试。其他 47 种物料、单板 99 件装配数量均保留。U1 仍为 ESP32-C5-WROOM-1U-N8R4；报价表备注的 N8R8 未自动作为替料采用。U2 仍实装 ML307R-DL。

## U6 核对

| 项目 | 现有 MAX3485ESA+ | SP3485EN-L/TR 候选 |
|---|---|---|
| 采购料号 | C1545222 | C8963 |
| 1～8 引脚 | RO、/RE、DE、DI、GND、A、B、VCC | 相同 |
| 通信 | 3.3 V 半双工 RS485，最高 10 Mbps | 相同功能类别与最高速率 |

| 现有焊盘 | 8 个约 0.6×1.8 mm 焊盘，排中心约 ±2.450 mm | 无需改变现有焊盘及旋转位置 |

现有 U6 八脚网络逐一核对：1=485_RX_RAW，2/3=MCU_485_DE，4=FIELD_TX，5=GND，6=RS485_A，7=RS485_B，8=VDD_3V3。

按 SP3485 原厂 POD-00000108 图，脚宽最大 0.51 mm，跨脚 6.00 mm，脚长最大 1.27 mm。现有焊盘覆盖其标称几何包络，横向余量约 0.045 mm/侧。本项未叠加贴装偏移、制造公差，也不代表工厂已经认可焊接工艺。

首板应核对：LTE 发射及 Wi-Fi 高负载时 3.3 V 电源处于新料范围，项目所需各档波特率、收发方向切换、总线空闲状态、实际线缆与节点通信。外部 SM712、串阻、偏置及默认选装终端位置均保留。

原工程、Gerber、原 BOM 和 CPL 的 SHA-256 均与当前交付清单一致。本次仅提供独立的采购候选 BOM，未修改工程中 U6 的原型号标注，未生成或替换 PCB 制造文件。贴装时 U6 的物料选择需要使用候选 BOM 中的 C8963；坐标沿用 V0.14.4 原 CPL。

## MAX3485ESA+T 的区别

ADI/MAXIM 的 MAX3485ESA+ 与 MAX3485ESA+T 功能、引脚和器件封装相同，T 是编带包装后缀。+T 对应的立创料号为 **C18148**，可作为不更换芯片的采购比价项。其他厂家使用近似 MAX3485 名称或附加厂牌后缀时，应按其自己的数据手册核对，不能因名称近似就按原厂包装替代处理。

## 本轮保留的高价项

| 项目 | 本轮处理 | 原因 |
|---|---|---|
| AP63300、TLV75901P、电感 | 保留型号与参数，允许同料重新询价 | 低价开关电源芯片通常还需核对引脚、控制方式、反馈与补偿、工作占空比及负载瞬态 |
| TXU0202 | 保留 | UART 需要两个相反传输方向及断电隔离，常见共享方向的双通道转换器不能直接代入 |
| 两颗 220µF 松下聚合物电容 | 保留 | 原料约 15mΩ ESR、3.16A 纹波；尚未核对出同焊盘、满足电气要求且有明显价格优势的替代料，不删除储能电容 |
| 两颗 USB 保护阵列 | 保留 | 低价常见 SOT-23 保护阵列与现有微小三脚封装不同，不通过修改保护功能或硬套封装降价 |
| 22µF、10µF 陶瓷电容 | 保留，优先同料比价 | 替代时须核对直流偏压后的有效容量，当前没有可计入节省的已确认人民币报价 |
| U1、U2、8 个 LED、3 个现场接口 | 保留 | 保持当前产品功能与软件架构 |
| 排阻 | 保留 | 用户报价中五块合计仅 4.5 元，改回分立器件可能增加贴装费用 |
