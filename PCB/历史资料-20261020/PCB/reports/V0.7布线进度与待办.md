# V0.7 布线进度与待办

2026-10-10。电路沿用 V0.6 精简版；本版更新布局和布线。工程已保存，仍未完成，不可投板。

## 本轮实际结果

- 写入并保存 113 段普通信号线、80 个过孔；随后移除了两颗距板边不足的 SIM 检测过孔，该网络需继续重布。
- ESP32、Air780EPT 两组 USB 主干实际几何回读与规划逐段匹配；分别为两条各 34.6361mm、两条各 62.7354mm。等长不代表阻抗、信号完整性或实物下载已验证。
- 修正 D21 USB ESD 的放置方向与接地，补齐移位器件的接地；SIM 时钟线绕开卡槽两处定位孔。
- 按当前过孔重新生成 L2 接地填充，256 个填充图元，约 3693.69mm²。下一次新增非 GND 过孔后需重新计算避让，图元清单见 current-ground-fill-v07.json。
- 最新嘉立创EDA DRC：0 个铜皮间距错误，59 个 Connection Error，涉及 24 个网络；当前 DRC 未列出 GND、USB 或射频的连接错误。此结果不代表完成硬件审查。
- 原理图未在本轮改变；508 项引脚断言与 587 个 PCB 焊盘校验属于 V0.6 的历史验证结果，本轮不重复声称已重跑完整校验。

## 必须继续处理

1. 调整 RS232 四颗电荷泵电容 C30～C33。当前距 U7 较远，不能仅靠长线连接；本轮检查了近芯片候选位置，但因器件与现有铜线阻挡，尚未完成移位。需先重排这个局部电路。
2. 完成 24 个剩余网络，包含 SIM、UART、接口检测、接口保护支路与部分 LED。重新规划时必须包含 SIM 定位孔、板边过孔退让和实际铜线，不可沿用忽略机械孔的旧规划。
3. USB 底层线路下方的 L3 地参考尚未补齐；两处 3.3V 铜线与 USB 投影重叠，需要局部调整。当前不能声称实现了 90Ω 差分阻抗。
4. LTE 射频共面接地、供电瓶颈/峰值电流与保护协调审查、BOM 属性校准、丝印重叠整理仍待完成。
5. 完整 ERC/DRC、最终焊盘网络回读与实物验证通过后，才能生成正式制造文件。本轮不输出生产 Gerber。
